## 👨‍💻 About me

I build SaaS applications end-to-end — from the database schema to the UI. Currently a **Full-Stack Developer at [Sislav](https://sislav.com.br)**, a SaaS/IoT platform for self-service laundromats, where I ship production features across the whole stack: TypeScript, NestJS, Next.js, Prisma, MySQL, Redis and RabbitMQ.

I picked up **Go** on my own through side projects and use it for backends where performance and simplicity matter. Outside of work I'm digging into distributed systems, event-driven architecture and the math behind machine learning.

- 🏢 **Sislav** — SaaS/IoT, real devices, real users, real money flowing through the system
- ⚙️ Production stack: TypeScript · NestJS · Next.js · React · Prisma · MySQL/Postgres · Redis · RabbitMQ · AWS
- 🐹 Go for personal projects: REST APIs, background workers, WhatsApp automation
- 🧠 Long-term interest in ML — neural networks from scratch in Go, calculus & linear algebra
- 🌍 Working towards international opportunities · English & French learner
- 🎓 Tecnólogo in Systems Analysis and Development · aiming for Computer Science at UFMT
